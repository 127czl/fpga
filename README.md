# Ti60F225 实时图像边缘检测与多模式视觉系统

**赛事提交版本：`v102clear_Competition_20261103`**  
**基线工程：`Ti60_v102_CirclePair_Final_20261031`**  
**目标器件：Efinix Titanium Ti60F225**  
**目标赛事：嵌入式芯片与系统设计竞赛 FPGA 赛道**

本项目是一套面向 1080P60 摄像头输入的纯 RTL、实时、多模式机器视觉演示系统。
系统使用 SC2210 低照度图像传感器，经 4-lane MIPI CSI-2 接收 RAW8 图像，
通过片外 DDR3 建立多帧缓存，再依次完成 Bayer 转 RGB、颜色校正、灰度化、
中值滤波、高斯滤波、Sobel 边缘检测、Canny 二值化、帧冻结、视频回放、
交通标志识别和圆形/矩形识别，最终由 HDMI 输出 1920x1080@60Hz 画面。

本包同时保留可综合源码、已生成位流、布局布线报告、演示素材和构建脚本，
既可直接烧录演示，也可在 Efinity 2026.1 中重新编译。

## 2. 设计目标与主要特性

本项目不是把多个互不相关的演示拼接在一起，而是让九项任务共享同一套
摄像头、DDR3、图像流水线、按键状态机和 HDMI 显示通路。

主要特性：

- 1920x1080@60Hz 实时采集与显示，无帧率降采样。
- 4-lane MIPI CSI-2 摄像头输入。
- DDR3 128 帧逻辑环，划分为录像区、实时预览区和快照区。
- 9 项可切换视觉任务，全部由板上两个按键完成操作。
- 3x3 中值滤波、3x3 高斯滤波、Sobel、NMS、双阈值迟滞完整硬件链路。
- 同一源行的左灰度、右边缘连续分屏，不使用两幅缩小图像拼接。
- 帧冻结、最多 16 张快照、多帧对比和 104 帧循环回放。
- 六类简化交通标志的检测、框选和中文状态提示。
- 基于掌心肤色区域进入 ROI 的无接触录制开始/停止触发。
- 边缘图上的圆形/矩形多目标检测，识别框和 ROI 指示线叠加显示。
- 纯 RTL 实现，不依赖软核、DDR 外部 PC 或上位机参与实时处理。
- 中文点阵字库 OSD、实时帧率、阈值偏移和任务状态显示。
- 场同步边界统一切换任务，并在切换时主动消隐 3 帧，避免花屏。

## 5. 系统总体架构

```text
                         ┌──────────────────────────────┐
                         │       DDR3 128-frame ring     │
                         │ 0..103 record / 104..111 live │
                         │       112..127 snapshot       │
                         └──────────────┬───────────────┘
                                        │ RAW8
 SC2210 ── MIPI CSI-2 ── CSI RX ── DMA ─┤
                                        │
                       ┌────────────────▼────────────────┐
                       │ RAW8 Bayer 3x3 -> RGB888        │
                       │ black level / WB / CCM / gamma  │
                       │ saturation / AGC / shadow guard │
                       └────────────────┬────────────────┘
                                        │
               ┌────────────────────────┼────────────────────────┐
               │                        │                        │
       colour delayed path       gray -> median -> gauss    traffic sign ROI
               │                        │                        │
               │                  Sobel strength           16x16 template
               │                    │        │                classifier
               │                 display   Canny NMS              │
               │                    │        │                   │
               └──────────── task mixer + OSD ──────────────────┘
                                        │
                                   HDMI/TMDS
```

关键点：

- 写 DDR3 的是传感器原始 RAW8，不是已经压缩的显示画面。
- 显示侧从 DDR3 读出 RAW8 后，使用 3x3 窗口做去马赛克。
- 彩色显示、灰度、Sobel、Canny、分屏和识别任务共用同一帧的时间基准。
- 任务切换、DDR 读写指针改变和回放状态改变，都在显示场同步下降沿生效。

## 6. 九项演示任务

屏幕左上角统一显示“任务 N + 中文功能名”，右上角显示实测帧率和阈值偏移。
任务 7、8、9 另外显示与该任务有关的状态或计数。

| 任务 | 屏幕名称 | 功能 | 主要数据通路 |
|---|---|---|---|
| 1 | 彩色直通 | 正常彩色画面 | RAW8 -> Bayer RGB -> ISP -> HDMI |
| 2 | 灰度显示 | BT.601 8-bit 灰度 | RGB -> Y -> HDMI |
| 3 | 边缘检测 | Sobel 边缘强度 | 灰度 -> 中值 -> 高斯 -> Sobel |
| 4 | 左右分屏 | 同一帧左灰度、右边缘强度 | 同一行像素的双路混合 |
| 5 | 二值边缘 | Canny 风格干净二值边 | Sobel -> NMS -> 双阈值 -> 迟滞 |
| 6 | 彩色叠加 | 彩色图叠加红色 Sobel 边 | 延迟彩色与 Sobel 同像素叠加 |
| 7 | 帧冻结 | 冻结、快照、多帧对比、交通标志识别 | DDR snapshot + template classifier |
| 8 | 录制回放 | 104 帧录像、循环回放、掌心触发 | DDR record ring + playback |
| 9 | 形状识别 | Sobel 图上的圆形/矩形检测 | 行带/列投影 + 边缘密度分类 |

### 6.1 任务 1：彩色直通

SC2210 RAW8 先进入 DDR3，显示侧读取后经过 `VIP_RAW8_RGB888` 完成 Bayer 插值。
随后 `VIP_RGB888_ColorCorrect` 完成黑电平、白平衡、颜色矩阵、Gamma、饱和度、
对比度、暗部色度抑制和软件 AGC。该任务用于检查摄像头、DDR 和 HDMI 主通路。

### 6.2 任务 2：灰度显示

灰度公式为：

```text
Y = (77*R + 150*G + 29*B) >> 8
```

三个权重之和为 256，因此满白像素仍然映射为 255，不会出现亮度比例偏差。

### 6.3 任务 3：Sobel 边缘强度

Sobel 计算使用：

```text
Gx = (p13 + 2*p23 + p33) - (p11 + 2*p21 + p31)
Gy = (p31 + 2*p32 + p33) - (p11 + 2*p12 + p13)
G  = |Gx| + |Gy|
```

使用绝对值之和代替平方根，避免除法和大位宽乘方。任务 3 输出 8-bit 边缘强度，
不是纯二值图，因此可以观察强弱边缘层次。

### 6.4 任务 4：同帧左右分屏

左半屏显示原始列 `0..959` 的灰度，右半屏显示原始列 `960..1919` 的 Sobel 强度。
两半来自同一源行的同一次采集，并非把两整幅图横向压缩后拼接。
`VIP_SplitScreen` 使用乒乓行缓存：当前行写入一个 bank，上一行从另一个 bank 读取，
避免同地址读写冲突，并保持左右两半的空间连续性。

### 6.5 任务 5：Canny 二值边缘

任务 5 在灰度、中值和高斯平滑之后执行：

1. Sobel 计算 `Gx`、`Gy` 和梯度幅值。
2. 将梯度方向量化到 0、45、90、135 度四类。
3. 沿梯度方向做非极大值抑制，把粗边缘细化到单像素。
4. 使用高、低双阈值分割。
5. 弱边缘只有与强边缘邻接时才保留，即单次迟滞连接。
6. 最终输出黑白二值边，不显示中间灰阶。

高阈值由“帧自适应阈值 + 按键偏移”共同决定，低阈值取高阈值的一半。
因此任务 5 能随室内亮度变化自动调整，同时保留人工调节能力。

### 6.6 任务 6：彩色图叠加红色 Sobel 边

彩色通路经过与 `gray -> median -> gaussian -> Sobel` 等量的三级行缓存延迟，
使彩色中心像素和 Sobel 边缘像素严格对齐。Sobel 判定为边缘的像素输出纯红色
`RGB(255,0,0)`，其他像素保留原彩色。

### 6.7 任务 7：帧冻结、快照、多帧对比和交通标志识别

任务 7 有三个显示状态：

| 状态 | 屏幕提示 | 行为 |
|---|---|---|
| 实时 | `当前 实时` | 显示实时彩色画面；交通识别默认开启 |
| 冻结 | `状态 已冻结` | 显示刚捕获的保护快照，画面静止 |
| 对比 | `多帧 对比` | 在已保存快照之间逐张切换 |

保存逻辑：

- 实时状态短按 `KEY1`：捕获一帧到快照槽，完成后进入冻结状态。
- 冻结状态短按 `KEY1`：恢复实时画面。
- 实时状态长按 `KEY1`：进入多帧对比模式。
- 对比状态短按 `KEY1`：循环切换下一张快照。
- 对比状态长按 `KEY1`：退出对比并返回实时画面。
- 最多保存 16 张快照；每帧同时保存对应的交通标志分类元数据。
- 切换离开任务 7 时，逻辑快照列表和计数会清空；DDR 物理区域不作为长期相册使用。

进入对比时如果还没有快照，系统会把当前实时环形缓存中的一帧登记为参考帧，
因此评委可以先长按进入对比，再观察单帧结果。

交通标志识别默认开启。长按 `KEY0` 可关闭/开启识别；关闭后帧冻结、快照和
多帧对比仍可正常工作，只是不再框选标志和显示中文类别。

### 6.8 任务 8：视频录制、循环回放和掌心触发

任务 8 有四个显示状态：

| 状态 | 屏幕提示 | 行为 |
|---|---|---|
| 待机 | `状态 待机` | 实时显示，等待开始录制 |
| 录制 | `开始 录制` | 写入 DDR 录像区，显示已录帧数 |
| 回放暂停 | `回放 暂停` | 已进入回放，当前画面暂停 |
| 正在回放 | `正在 回放` | 按显示场同步逐帧推进，结束后自动循环 |

最大录像长度为 104 帧。按 60Hz 场频计算，完整录像约 1.73 秒。
录像达到上限后自动停止，防止覆盖快照区和实时预览区。

进入回放时不清空已录内容；退出回放、再次开始录制时才建立新的录像起点。
长按 `KEY1` 在“录制/待机”和“回放”模式之间切换，短按 `KEY1` 控制开始、
停止、播放和暂停。

掌心触发只用于待机和录制状态：

- 中央 ROI 内检测到满足面积和宽高约束的肤色掌形区域。
- 掌形稳定约 4 帧后产生一次触发。
- 触发后必须先离开 ROI 12 帧，再经过冷却时间，才允许下一次触发。
- 左右背景守望区用于检测整机/镜头运动；背景运动大时不触发，降低误报。
- 回放状态自动禁用掌心触发。
- 长按 `KEY0` 可关闭/开启掌心触发。

该功能是“掌心进入触发”，不是多类别手势分类，也不识别剪刀手、数字手势或轨迹。

### 6.9 任务 9：圆形与矩形识别

任务 9 使用 Sobel 边缘强度作为输入，背景显示边缘图，检测结果使用彩色线条覆盖：

- 黄色线框：矩形。
- 青色圆环：圆形。
- 暗青色矩形：当前识别 ROI 边界。
- 左上角显示圆形、矩形数量。

检测流程：

1. 在选定 ROI 内做行带投影，找到边缘连续且跨度足够的候选行带。
2. 在候选行带内做列投影，最多保留 4 个分离的列游程。
3. 合成候选包围盒，并执行边长、面积和边界保护筛选。
4. 在下一帧用边缘密度、径向分布和行跨度区分圆形和矩形。
5. 只有同时满足几何条件和面积条件的候选才输出框线。

默认面积阈值为 `64,800` 像素，约为整幅 1920x1080 图像的 `1/32`。
同时限制最短边 120 像素、最长边 1000 像素、最大包围盒面积 1,000,000 像素。

任务 9 支持最多 4 个分离候选。对于重叠、粘连、极低对比度、强反光或严重透视
变形的图形，识别稳定性会下降；现场演示应让图形完整落在 ROI 内。

## 7. 按键操作总表

按键在 FPGA 内部上拉，按下接地，低电平有效。消抖时间约 10ms，
长按判定约 0.4 秒。长按只产生一次事件，不连续快速重复。

### 7.1 KEY0

| 当前任务 | 短按 | 长按 |
|---|---|---|
| 任意任务 | 进入下一任务；任务 9 后回到任务 1 | 任务 7：开关交通标志识别 |
| 任务 1 至 6 | 进入下一任务 | 返回上一任务；任务 1 返回任务 9 |
| 任务 7 | 进入任务 8 | 开关交通标志识别 |
| 任务 8 | 进入任务 9 | 开关掌心触发 |
| 任务 9 | 回到任务 1 | 切换识别 ROI：100% -> 80% -> 60% -> 45% -> 100% |

### 7.2 KEY1

| 当前任务 | 短按 | 长按 |
|---|---|---|
| 任务 1 至 6、任务 9 | 阈值偏移 `+8` | 阈值偏移 `-8` |
| 任务 7 实时 | 保存快照并冻结 | 进入多帧对比 |
| 任务 7 冻结 | 恢复实时 | 进入/退出多帧对比的上下文切换 |
| 任务 7 对比 | 下一张快照 | 退出对比，回到实时 |
| 任务 8 待机/录制 | 开始或停止录制 | 进入回放 |
| 任务 8 回放 | 播放/暂停 | 退出回放 |

阈值偏移范围是 `-1536..+1536`。每次按键只改变 8，便于现场细调。
实际 Sobel 阈值等于“帧自适应阈值 + 人工偏移”，并限制在 `0..2040`。

## 8. 图像处理算法原理

### 8.1 3x3 行缓存

所有 3x3 算子共用 `VIP_Matrix_Generate_3X3_8Bit` 的两行 BRAM 结构。
第 1 行缓存写入当前行，第 2 行缓存提供上一行，配合当前行组成 `p11..p33`。
当一行结束时交换读写角色，从而在不复制整帧的情况下完成逐像素卷积。

### 8.2 中值滤波

`VIP_Median3x3` 使用 21 个比较交换单元实现 9 点中值：

1. 三行分别排序。
2. 取三行最小值、中值、最大值的各自中值。
3. 再对这三个结果做一次中值。

相比排序循环，该网络完全并行、延迟固定，适合 148.5MHz 像素时钟。

### 8.3 高斯滤波

高斯核为：

```text
1 2 1
2 4 2  / 16
1 2 1
```

所有乘法都通过移位和加法实现。中值先去除传感器孤立坏点，高斯再平滑细小噪声，
为 NMS 提供连续梯度，减少断点和孤立白点。

### 8.4 自适应阈值

`VIP_AdaptiveThreshold` 每 16 个有效像素采样一次 Sobel 幅值，统计整帧平均梯度。
阈值取平均梯度的 3 倍，并限制在合理范围。暗场景自动降低阈值，亮场景自动提高阈值；
按键偏移在此基线上叠加。

### 8.5 NMS 和双阈值迟滞

`VIP_NmsEdge` 将梯度方向归一化为四个方向，对梯度幅值、方向和灰度做三个像素对齐的
3x3 窗口。仅保留沿梯度方向的局部极大值，再使用高低阈值和八邻域强边连接。
该步骤去掉粗边缘和孤立响应对应的白点。

### 8.6 彩色校正

`VIP_RGB888_ColorCorrect` 的主要步骤：

- 黑电平扣除。
- Q8 定点红、绿、蓝白平衡增益。
- 3x3 颜色校正矩阵。
- Gamma 编码。
- 饱和度和对比度调整。
- 暗部色度抑制，减少黑区偏色。
- 基于帧平均亮度的慢速 AGC。
- 绿色背景抑制，降低中性背景偏绿。

当前顶层参数为红/蓝增益 `352/256`、绿增益 `256`，并通过自动增益在
`0.5x..1.5x` 范围内缓慢调节。

## 9. DDR3 多模式帧调度

DDR3 逻辑上划分为 128 个帧槽，每槽保存一幅 1920x1080 RAW8 帧：

| 槽位 | 数量 | 用途 |
|---|---:|---|
| `0..103` | 104 | 视频录像区 |
| `104..111` | 8 | 实时预览环 |
| `112..127` | 16 | 冻结快照区 |

设计要点：

- 实时预览使用 8 槽小环，降低正常显示延迟。
- 录像被限制在 104 帧，防止覆盖快照区。
- 快照通过独立 `snapshot_slot` 写入，不被预览环覆盖。
- 快照完成后才更新显示索引和分类元数据，避免读到半帧。
- 任务切换不直接复位 DDR 读写指针，防止已发出的 AXI burst 写入错误帧。
- 回放地址按 112 取模，不跨入快照区。
- 冻结、播放、对比和任务切换均产生 3 场消隐，清空行缓存和读 FIFO 的残留。

视频回放时，屏幕按显示场频从录制区逐帧读取，播放速度与 HDMI 60Hz 对齐，
与摄像头实际帧率显示计数相互独立。

## 10. 交通标志识别器

交通标志识别位于任务 7，不再占用单独任务号。历史源码注释中的 “Task 10”
指的是该识别模块，已在最终工程中并入任务 7。

### 10.1 识别范围

当前支持六张简化演示标志：

| 类别编号 | 标志 | 关键判据 |
|---:|---|---|
| 0 | 施工路障 | 红黄边框 + 黑色内部图案 |
| 1 | 注意行人 | 红黄三角形 + 行人图案 |
| 2 | 左弯警告 | 红黄三角形 + 左弯箭头 |
| 3 | 禁止通行 | 红色圆形 + 白色中央横杠 |
| 4 | 限速 30 | 红色圆形 + 黑色数字 30 |
| 5 | 停车指示 | 大块蓝色区域 + 白色 P |

### 10.2 ROI

交通标志专用 ROI 为 `336x336`：

```text
X = 792..1127
Y = 372..707
```

ROI 位于 1080P 画面正中央。任务 7 的 OSD 会画出该矩形范围，便于将图卡放准。
如果图卡只露出一个角，候选宽高比和边界保护会拒绝该帧。

### 10.3 处理流程

1. 对红色边框做颜色候选检测。
2. 统计连续游程，形成候选包围盒。
3. 对蓝色大区域使用独立通道检测，专门覆盖停车标志。
4. 在候选框内建立 `16x16` 网格。
5. 每个网格通过中心、上下左右五个点做颜色投票。
6. 将 256 个网格类别与六类模板逐格比较，累计汉明距离。
7. 使用最佳/次佳类别距离裕量抑制不确定结果。
8. 连续多帧类别一致后才输出有效标签，减少闪烁。
9. 禁止通行和限速 30 增加中央黑色网格专项判别：
   - 黑色网格 `<= 2`：禁止通行。
   - 黑色网格 `>= 7`：限速 30。
   - `3..6`：沿用模板距离分类。
10. 停车标志使用弱蓝候选、蓝色区域占比和蓝区包围盒作为独立判据。

识别结果以类别颜色框出，并在左上角显示对应中文名称。冻结后的每一张快照
同时保存该帧的类别和有效位，多帧对比时继续显示历史识别结果。

演示素材是简化图形，不是官方交通标志，只用于算法演示，不能用于真实道路安全系统。

## 11. 掌心触发识别器

任务 8 的掌心触发不是神经网络，而是针对低照度摄像头的轻量肤色区域状态机。

参数：

| 参数 | 值 |
|---|---:|
| ROI | `X=680..1239`，`Y=380..699` |
| ROI 尺寸 | `560x320` |
| 采样方式 | ROI 内每 16 像素采一点 |
| 肤色面积 | `4000..170000` 像素 |
| 肤色块宽 | `50..520` |
| 肤色块高 | `50..300` |
| 稳定触发 | 4 帧 |
| 离开重新布防 | 12 帧 |
| 触发冷却 | 20 帧 |
| 帧差阈值 | 18 |

状态机流程：

1. 在中央 ROI 内做肤色筛选和面积统计。
2. 限制肤色连通块的宽高，排除小色斑和整屏偏色。
3. 判断 ROI 外左右守望区是否发生大面积亮度变化，减少镜头移动误触发。
4. 掌心在 ROI 内连续稳定约 4 帧后产生单次事件。
5. 掌心离开足够帧数且冷却完成后才重新布防。
6. 事件只在待机或录制状态生效，因此可用于开始录制和停止录制。

现场使用时，手掌应完整进入中央青色框。手掌只占很少面积或移动过快时可能不触发。

## 12. 显示混合与中文 OSD

`VIP_TaskDisplay` 根据当前任务选择四类像素源：

- 彩色直通。
- 灰度/ Sobel / Canny / 分屏。
- DDR 冻结或回放图像。
- 任务 9 形状识别叠加图。

`isp_task_osd` 是所有文字的最终叠加层，避免多个 OSD 模块重复写同一行。
OSD 包含：

- 左上角任务编号和中文功能名。
- 右上角实测帧率和阈值偏移。
- 任务 7：实时、冻结、对比状态与快照编号。
- 任务 8：待机、录制、暂停、回放状态、帧数和掌心提示。
- 任务 9：圆形和矩形数量。
- 任务 7：六类交通标志中文名称。

中文字模存放在 `src/isp/isp_chinese_font_16x16.v`、`isp_chinese_font_32x32.v`
和 `task_badge.mem`、`status_badge.mem`、`icon_label_badge.mem` 中。
文字使用阴影增强复杂背景下的可读性，不添加大面积半透明底板。

帧率不是固定写死的 60，而是以 148.5MHz 像素时钟建立 1 秒窗口，
统计摄像头帧开始脉冲后显示实际值。

## 13. 跨时钟域与防花屏设计

系统中同时存在：

- 摄像头 CSI 像素时钟。
- DDR3 控制器 `core_clk` 和 `clk_sys`。
- 148.5MHz 显示像素时钟。
- HDMI 串行时钟。

防花屏措施：

- 摄像头帧计数和 DDR 帧索引先经过两级同步器。
- 任务选择在 HDMI 场同步下降沿统一切换。
- 切换任务、冻结、对比、录像或回放状态变化时，读通路消隐 3 场。
- 行缓存和 FIFO 在消隐期间重新装填，不再显示新旧任务混合像素。
- 快照完成信号通过同步翻转位跨时钟域，不直接跨域传递多比特地址。
- 播放地址限制在录像区域内，避免跨入快照内存。

## 16. 现场演示建议

### 16.1 任务 1 至 6

- 先放白色物体，确认自动增益和白平衡稳定。
- 再放彩色物体，展示彩色直通。
- 对同一场景依次切换灰度、Sobel、分屏和 Canny，评委可以直观看到链路递进关系。
- 用 `KEY1` 短按/长按小幅调整阈值，避免一次改变过多。

### 16.2 任务 7

- 进入任务 7 后先让交通标志完整位于中央 ROI。
- 等中文类别稳定后，再短按 `KEY1` 保存快照并冻结。
- 恢复实时后换一张标志，再保存第二张。
- 长按 `KEY1` 进入多帧对比，逐张展示历史分类结果。
- 长按 `KEY0` 关闭识别后，画面恢复到不含交通框选的普通冻结模式。

### 16.3 任务 8

- 先短按 `KEY1` 开始录制，保持画面变化约 1 至 1.7 秒。
- 再短按停止，长按进入回放，短按播放/暂停。
- 掌心触发演示时，把手完整伸入中央青色框，稳定片刻后移出。
- 若现场背景或灯光变化大，先长按 `KEY0` 关闭掌心触发，使用按键稳定演示。

### 16.4 任务 9

- 使用空心圆形、空心矩形或简单边缘图卡。
- 图形应完整落在青色 ROI 内，面积应大于全屏约 `1/32`。
- 先用大图形验证，再切换到 80%、60% 或 45% ROI 缩小搜索范围。
- 黄色框表示矩形，青色环表示圆形。
